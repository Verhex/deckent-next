# Changelog

This is the changelog of the beta line, continuing from [CHANGELOG-alpha.md](CHANGELOG-alpha.md) (alpha.1 – alpha.64; last alpha 1.0.0-alpha.64, merged `fa244dd3d`, live and N1 2026-11-10, ledger v75, runtime protocol v31).

Human-curated. Every live beta release bumps the version (`1.0.0-beta.N`, SemVer pre-release) and adds exactly one line: version, date, landed commit and what it brings, keyed by PLAN.md card ids. Details live in PLAN/COMPLETED-PLAN, ARCHITECTURE and Git history. No product code writes this file.

- **1.0.0-beta.1.2** — Unreleased · (owner 2026-11-11: fix release; ledger v75 and runtime protocol v31 unchanged) · **Claude turns work again after a CLI update:** Claude CLI 2.1.322 loads built-in plugins the allow-list did not name, so every Claude tool turn was refused when it started. Built-in plugins are now accepted as a class: a plugin passes only when the CLI reports it with the built-in path and its own built-in source; a built-in name deckent has not seen before is shown as a note and kept in the record when a terminal tool turn completes (owner-accepted limit of this release: not when the turn is cancelled, times out or fails, and not for planner calls and worker runs; see known limits); plugins a user installs are still refused, as is a second plugin with the same name. The text-chat path now checks the plugin's source and duplicate names too. deckent does not look at what a built-in plugin does; known limits say what it can and cannot see.

- **1.0.0-beta.1.1** — 2026-11-11 · `f9490884e` (PR #149; live 2026-11-11 19:10Z and N1 19:12Z, switch `f9490884ed61-35e40120a119`) · (owner 2026-11-11: interim release before beta.2; ledger v75 and runtime protocol v31 unchanged) · **The terminal wears the brand:** the startup mark is the logo's lowercase d, five rows by default and ten rows in a window of at least 100 columns and 30 rows, with an ASCII d for limited terminals. The dark and light themes take the brand palette: teal for deckent's own label, window titles and the mode indicator; blue for links, code, information and model names; new success, warning and error colours; muted text for hints, provider names and frames; the selected row is drawn on the palette's selection background where the terminal can show it. The colour-vision and high-contrast themes and the 16-colour themes are unchanged. deckent still never paints the terminal's own background.

- **1.0.0-beta.1** — 2026-11-11 · `049a208f4` (PR #148; live 2026-11-11 11:31Z and N1 11:32Z, switch `049a208f455f-cd284ae62f2b`) · (owner 2026-11-11: alpha.64 was the last alpha; improvements continue as beta.2, beta.3…; the eight acceptance gates remain open during the beta line and beta acceptance is announced separately; ledger v75 and runtime protocol v31 unchanged) · **Names first in /model and /provider:** each opening shares one read snapshot; names appear with “Checking…” until their row checks finish, and pending rows cannot be selected. Closing or reloading discards late results; commands chosen from help keep their own gates. **Local timing, when you ask:** `DECKENT_TIMING_TRACE=1` records content-free command timing locally; `deckent doctor timing` summarizes it. **Clearer first use after the alpha.64 BeUser re-walk:** a fresh audit row gives the `audit verify` next step; repeated rows collapse; setup gives one final-check message and does not count optional untested tool-version rows as work waiting. The first-work card says when no coding CLI is installed and how to get one. The narrow-permission question says what changes; the key screen describes its selected store. `terminal attach` preview prints the complete apply command and help marks `--command-id` as required. Source builds check Docker reachability before the long build and show the matching start command. **The name is deckent:** the terminal, CLI text, current documentation, the instructions models read and the default author of new delivery commits write the name in lowercase, and the terminal opens with a new mark (a reaching arm). Deliveries queued under the old author name still replay; existing commits are not rewritten; provider sign-in names are unchanged. **Work starts when one worker kind is ready:** planning no longer waits for every worker image; a missing or unverified image holds back only its own kinds, `deckent coding` and `deckent doctor` name each unavailable kind (`workerKinds` in doctor JSON), and a plan that names an unusable kind is refused with the usable ones listed. **Documentation pass:** README, install guides, architecture overview and known limits were checked against the candidate and corrected. **One clean frame after a resize:** resizing the full-window terminal no longer leaves a second copy of the mark or the help rows; a draft, an open card and a running answer survive, and nothing is drawn while another screen (setup, the editor, a sign-in) holds the terminal. README gained the steps to update an existing source install; known limits describe the installation-moved state on WSL. **Working room:** architecture, file and test budgets were raised by the owner on 2026-11-11; this is no capacity claim.
