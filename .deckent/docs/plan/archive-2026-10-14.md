### ARCHITECTURE (işçi bağlamı paragrafı)

Worker context (DECKENT-MD-WORKERS, landed in alpha.53) is separate from this terminal trust. At admission a Run reads the work target's selected worker file once (`execution.workerInstructions.source`: `worker-md` = `.deckent/worker-instructions.md` (the default when present), `agents-md` = `AGENTS.md`, or `none`; without Git execution it is an explicit no-op) and passes it only when a person trusted that exact digest with `deckent coding instructions trust` (the existing `config`/`write` cell for `project:execution.workerInstructions`, refused to every AI actor, sealed as an `authority-decision` before the trust record changes). Otherwise workers get the task text only and Run creation warns `WORKER_INSTRUCTIONS_WITHHELD`. `compileNativeCodingWorkInput` appends the snapshot after the template's own `composition.context` within the same 16 KiB part / 32 KiB composition bounds; a snapshot that does not fit is `WORKER_INSTRUCTIONS_TOO_LARGE`. Summary: [Subscription coding workers](#subscription-coding-workers--owner-2026-09-21). Terminal reader author verification: external `proof/DECKENT-MD-2026-10-08/WORKER.md`.

### config-and-cli-help (işçi talimatları)

Worker instructions (alpha.53 F1): `deckent coding instructions [status] | trust | revoke [--target <id>] [--scope <id>]`.
Config `execution.workerInstructions.source` is `worker-md` (`.deckent/worker-instructions.md`, default when the file exists),
`agents-md` (`AGENTS.md`) or `none`; the file is read at the Git work target root, once per admission, bounded. `status` is read-only
(`--json` allowed). `trust` and `revoke` are decided on `config`/`write` for `project:execution.workerInstructions`, sealed before the
record changes, and need the person's terminal witness: a card shows path, size, sha256 and the first lines; AI actors, MCP, pipes and
`--json` are refused. Trust holds for exactly that folder and digest; a change makes it untrusted. Untrusted: workers get the task text
only and run create, MCP and `--json` carry `WORKER_INSTRUCTIONS_WITHHELD`.
