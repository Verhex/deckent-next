# Alp Discipline karar çapası

Legacy Alp Discipline dersi: kapsam dışını bil (negative space), sınır içi alternatif üret, kalite kaybında dur veya küçült, kararın hangi düzeyde olduğunu belirt (irtifa ilanı). Bu ilkeler kalite düşürmek için değil güvenli ilerlemek içindir. Legacy `alp-discipline/ESSENCE.md` tarihsel kaynaktır; Next'te kurulmuş gate veya yeni yetki sayılmaz.
