# Model invocation billing axis

**BILLING-EKSENI N2-0 (2026-10-15; landed in alpha.39):** invocation profile v2 requires `billingAxis: subscription | metered | local`; strict v1 dual-read injects no default and preserves its canonical encoding/digest and stored replay. A subscription profile must match the bound native port's explicit subscription capability; tariff-based HTTP ports cannot acquire it through profile relabelling. The engine skips monetary quoting/capacity for this path, while identity, invoke policy, activation, binding, profile freshness, allocation, single-use send permission and cancellation still apply. Metered v2 retains the budget and atomic reservation, including when a tariff happens to be zero; local v2 requires the existing literal-loopback/zero-tariff evidence. Legacy v1 behavior stays unchanged.

The engine creates a versioned non-monetary `plan-usage` settlement from the exact terminal invocation. Provider counters, when present, are retained independently of money; missing counters remain null/unavailable, and CLI cost estimates are excluded. Ledger55 appends this record in the same transaction as outcome/allocation settlement; no monetary account or reservation is created. Scope, invocation, profile digest and outcome digest bind the record; reads verify its checksum and retained response counters, and purge retains it. Existing ledger rows are untouched; the service-start consistent backup precedes migration, and rollback restores that backup rather than deleting new evidence. Invocation inspection adds optional `planUsage` for v2 profiles; v1 inspection stays byte-compatible. New model connections emit v2 profiles; reconnect preserves authored v1 and explicit v2 axes. New Brain contributions use v2 with an axis bound to the source receipt; v1 contributions still replay. Invocation inspection text, planning summaries and monitor task details render the typed axis through EN/TR catalogues. Real subscription transports, quota handling and live acceptance belong to their admitted follow-on cards; this candidate has no independent PASS.
